# AI tools statement — draft for submitter review

The project was developed collaboratively with OpenAI Codex. The assistant wrote and modified code, ran data and model experiments, created the browser interface and deployment configuration, and helped draft the documentation. The submitter directed the scope and challenged the low ranking scores and the cost of increasingly complex experiments. The submitter should review this statement and the implementation, and add any other tools or contributions before submitting it.

A significant error was the assistant's earlier suggestion that a roughly 50–70k-paper slice would likely preserve quality without first measuring author-history coverage. On the same validation queries, the nine-venue history covered 464 of 686 labelled author instances (67.64%); a predeclared expansion to related venue families covered 534 (77.84%). We corrected the plan, measured retrieval on the same cohort, and documented the remaining limitations. This comparison uses future-authorship proxy labels and a previously inspected validation set; it does not prove that the larger slice is globally optimal. See [the journal](project-journal.md) and [data audit](../resources/results/lean-data-v1.json).
